Технический аудит и локальные исправления выполнены. Основной игровой цикл,

Приложенное ТЗ прочитано полностью: фактический файл заканчивается в разделе 13
на строке «Исправление таймеров». Выполнены доступные требования из полученного
текста. [Карта архитектуры и исходные находки](ARCHITECTURE_AUDIT.md).

## Исправления

- Android Back/Escape: Language → Settings → сад; повторный Back при закрытом
  окне выполняет штатный выход. Закрытие ОС сохраняет снимок до выхода; лишняя
  повторная запись из второго обработчика удалена. Системные жесты iOS не добавлялись.
- Настройки: валидация типов, последняя рабочая резервная копия, восстановление,
  архив повреждённых байтов `.rejected-*`. Некорректный файл не перезаписывается
  молча при запуске. Явная смена настройки может восстановить запись после архивации.
  Обычная загрузка исправных настроек больше не создаёт лишнюю запись.
- Повторное чтение недоступного/повреждённого world save сохраняет живую модель
  и блокирует команды. Оно не подменяет текущий баланс стартовыми 150 монетами.
  При восстановлении backup повреждённый primary архивируется до замены.
- Полная проверка кандидата снимка выполняется **до** записи обоих файлов.
  Некорректный timestamp, в том числе экстремальное системное время за пределами
  формата, не создаёт нечитаемое следующее сохранение и не списывает монеты.
- Tweens посадки отслеживаются и отменяются при rebuild, удалении crop и Reduced
  Motion. После быстрых замен/закрытий диалогов сразу удаляются старые bindings.
  Фоновые циклы больше не перескакивают назад раз в минуту.
- Пустая/внешняя геометрия OS safe area получает безопасные обычные отступы.
  Возврат в приложение обновляет layout. Короткие портретные окна используют
  адаптивную высоту canvas вместо сжатия фиксированных 844 units. Текст не уменьшается
  внутри элементов ради перевода; на телефоне физический размер зависит от DPI.
- Списки диалогов прокручиваются при недостатке высоты. Карточки семян растут
  по фактической высоте текста; длинные переводы могут требовать вертикального
  скролла. Заголовок/Close и подтверждение посадки остаются доступны.
- В тесном overview первый tap приближает карту без посадки/сбора. Следующий tap
  работает с корректным ID; при zoom используется преобразование Camera2D.
- Карта обрезается по фиксированной игровой области и при максимальном zoom
  не рисуется под прозрачными надписями HUD. Основные позиции HUD при 390×844
  и 430×932 не изменены.
- Неизменяемые environment/bed отрисовываются в прозрачные SubViewport один раз.
  Оригинальная геометрия сохранена; знак обновляется при смене языка. Растения,
  выделение и ambience остаются живыми слоями. Плагины/ассеты/SDK не добавлены.

Схема сохранения остаётся **2**, миграция 1→2 сохраняется. Resources растений,
экономики и стартового региона, цены/награды/длительность роста и CSV переводов
не изменялись. Уровень остаётся существующей статической меткой 1; новый XP не добавлен.

## Измеренная производительность

Настоящий Compatibility/OpenGL-рендер **Mesa llvmpipe, Linux/Xvfb**, окно 390×844.
Это программный рендерер CPU на общей облачной машине. Каждый сценарий — 600
кадров после прогрева; ограничение 60 FPS не означает достигнутые 60 FPS.
Часть headless QA выполнялась параллельно; frame-time результаты не являются
контролируемым сравнением аппаратных GPU. Детерминированное уменьшение draw calls
и сохранение внешнего вида подтверждены отдельно.

| Сценарий | Draw calls p50 до → после | Frame p50, мс до → после | Frame p95, мс до → после |
| --- | ---: | ---: | ---: |
| Пустой сад | 1976 → **214** | 78.076 → **38.282** | 143.414 → **72.009** |
| Девять зрелых растений | 2156 → **394** | 99.981 → **31.679** | 272.502 → **44.878** |
| Reduced Motion | 2131 → **394** | 102.034 → **32.716** | 231.397 → **61.379** |
| Открытие/закрытие диалогов | 2165 → **428** | 101.038 → **42.608** | 231.280 → **69.597** |

Пустой сад: **−89.2%** команд; девять растений: **−81.7%**. Peak RSS процесса
290.4 → 242.0 MiB. CPU user+system за одинаковый полный прогон:
553.5 → 214.3 секунд; elapsed 333.2 → 144.7 секунд. Software GPU потребляет CPU;
нагрузка и энергопотребление настоящего GPU не измерены.

В финальном прогоне был единичный frame-time пик **2919.217 мс** в Reduced Motion
на общей машине. Он сохранён в исходных данных и не исключён из результата.
Медиана около 30 FPS в software renderer не подтверждает цель 60 FPS на Android.
[До](measurements/render-before.json), [после](measurements/render-after.json),
[CPU/RSS до](measurements/render-before-process.json),
[CPU/RSS после](measurements/render-after-process.json).

**Непрерывная сессия финального кода:** 300.021 секунды после прогрева,
297 циклов открытия/закрытия, языки, Reduced Motion и zoom. Во всех замерах:
125 nodes, 1805 objects, 15 bindings, 0 orphan nodes; текстурная память
21 653 553 байта без роста. Static memory 36 934 343 → 36 964 771 байт
(+30 428, около 0.08%; включает накопление массива измерений).
Прогрессирующего роста узлов/объектов/текстур не обнаружено. Пять минут не заменяют
30-минутный нативный soak и не доказывают отсутствие всех возможных утечек.
[Данные](measurements/soak.json), [лог](logs/soak.log).

сад/семена × 390×844/430×932; дополнительно 320×568, 360×640, 768×1024,

В основных видах сада девять грядок видны. В проверенных экранах нет наложений
кнопок и выхода диалогов за экран. Длинные карточки доступны через предусмотренный

## Мобильная сборка и оставшаяся приёмка

Добавлены Android/iOS export presets; тесты/отчёты исключены, font notices включены.
Android export validator действительно запускался и **не смог создать APK**:
нет 4.6.3 android_debug/release templates, Android SDK/platform-tools/build-tools,
настроенного Java SDK path. [Точный вывод](logs/android-export-validation.log).
PCK не содержит нативного движка и не заменяет APK/подписанный iOS build.

[Инструкция сборки и незаполненная аппаратная матрица](MOBILE_ACCEPTANCE.md).
Остаётся подтвердить на устройствах установку/обновление с сохранением данных,
реальный pinch/touch, Android Back, жесты iOS, вырезы/Dynamic Island, системные панели,
DPI/display zoom/размер текста, сворачивание/блокировку/force stop/перезагрузку,
часовые пояса/полночь, хранилище и 30-минутный performance/thermal/battery тест.
Системный Reduced Motion через отдельный native SDK не интегрирован; собственная
настройка игры работает. Редактура переводов носителями языка и screen reader QA
также остаются открытыми.

Локальная игра использует UTC timestamps и не требует фонового процесса. Она не
гарантирует защиту от намеренной подмены часов/файлов. Если обе копии нечитаемы,
неизвестные данные не восстанавливаются из ничего: запись блокируется, байты
сохраняются. Backup может содержать предыдущую целую транзакцию. Файловая атомарность
и поведение при внезапной потере питания на телефоне требуют проверки платформы.
В Xvfb есть ожидаемое предупреждение о неподдерживаемой смене VSync; штатные запуски
не содержат ошибок GDScript/ресурсов.

## Повторение проверок

Из корня проекта, Godot 4.6.3 в PATH:

```sh
godot --headless --path . --editor --import --quit
for suite in phase_zero phase_half phase_three_quarters gameplay gameplay_ui stabilization mobile_layout; do
  godot --headless --path . --script res://scripts/tests/$suite.gd
done
python tests/run_crash_recovery.py
```

Выполнять наборы последовательно: каждый использует отдельные QA-файлы, но два
одновременных экземпляра одного набора не поддерживаются. Настоящий restart:
preferences_restart.gd и world_restart.gd — режимы write/read/cleanup отдельными
командами; gameplay_restart.gd — cleanup/write/resume/verify_claimed/cleanup.
real_clock_restart.gd — cleanup/write, закрыть процесс, подождать ≥30 секунд,
затем read/claimed/cleanup отдельными командами. Ни один тест не меняет часы ОС.

С графическим дисплеем (например DISPLAY=:99):

```sh
godot --path . --audio-driver Dummy --max-fps 60 --script res://scripts/tests/performance_audit.gd -- /absolute/render.json 600
godot --path . --audio-driver Dummy --max-fps 60 --script res://scripts/tests/soak_audit.gd -- /absolute/soak.json 300
godot --path . --audio-driver Dummy --script res://scripts/tests/capture_gameplay.gd -- /absolute/screenshots
godot --path . --audio-driver Dummy --script res://scripts/tests/capture_mobile_audit.gd -- /absolute/screenshots
```

Для чистых performance-чисел остановить остальные QA-процессы. В ограниченном
Linux нужны доступные XDG_DATA_HOME/XDG_CONFIG_HOME/XDG_CACHE_HOME; в сессии —
`/tmp/mg-qa/{data,config,cache}`. Пользовательский save на телефоне не использовался.
Сетевые сценарии неприменимы: игра offline, HTTP-клиента нет.
