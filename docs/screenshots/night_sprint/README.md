## Как подготовлено состояние
capture_gameplay.gd использует отдельные файлы сохранений/настроек и внедрённые
тестовые часы. Через настоящие команды он выращивает и собирает 50 морковок,
затем сажает девять растений. Шесть зрелых видов и три младшие стадии дают
возможность проверить все 24 позы и композицию; общий баланс сада — 41 монета.
Перед кадрами панели семян одна морковь собрана, баланс — 51, поэтому дорогие
семена честно недоступны. Основное пользовательское сохранение не изменяется.
В новой игре будут пустые грядки, 150 монет и нулевой счётчик урожая.

Для повторяемости время окружающей анимации остановлено на 2.25 сек. Для
проверки движения нужно запустить игру; статичные PNG его не демонстрируют.
Скрипты захвата и команды приведены в README проекта. Артефакты сравнения до/после
архитектурной переделки находятся в ../phase_0_75, включая comparison и navigation.

Программный OpenGL предупреждает о неподдерживаемом VSync. Ошибок GDScript,
ресурсов или сохранения во время захвата нет. Физические устройства не проверялись.
